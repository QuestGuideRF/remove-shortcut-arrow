# Удаление стрелок с ярлыков Windows

Программа для удаления стрелок с иконок ярлыков на рабочем столе Windows через изменение реестра.

![Пример иконок со стрелками](1.jpg)

## ⚠️ Важно

- **Требуются права администратора** для изменения реестра
- Перед использованием рекомендуется создать резервную копию реестра:
  - Нажмите `Win + R` → `regedit` → Enter
  - Файл → Экспорт → Сохраните резервную копию

## 🚀 Использование

### Запуск программы

1. Запустите программу **от имени администратора**:
   - Правой кнопкой мыши на файл → "Запуск от имени администратора"

2. Или через командную строку (от имени администратора):
   ```bash
   python remove_shortcut_arrow.py
   ```

### Функции программы

1. **Убрать стрелку** - создает параметр с пустым значением
2. **Восстановить стрелки** - удаляет параметр из реестра

## 📋 Что делает программа

Программа изменяет реестр Windows:
- **Путь**: `HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Explorer\Shell Icons`
- **Параметр**: `29` (строковый)
- **Значение**: пустое

## 🔄 Восстановление

Если нужно вернуть стрелки:
- Используйте опцию "3. Восстановить стрелки" в программе
- Или вручную удалите параметр `29` из реестра

## ⚙️ Требования

- Windows 7/8/10/11
- Python 3.x
- Права администратора

## 📝 Примечания

- После изменения реестра необходимо перезапустить проводник или перезагрузить компьютер
- Программа автоматически предлагает перезапустить проводник
- Все изменения обратимы
